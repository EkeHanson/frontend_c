DOM Selectors: ID & Tag Name

Task: Write JavaScript to select and modify elements using getElementById and getElementsByTagName.

  • Create an HTML page with:
    • An element with id="main-title"
    • At least 3 paragraphs (<p>)
  • Use JavaScript to:
    • Change the text of the element with id="main-title" using innerHTML
    • Change the color of all paragraphs using getElementsByTagName
<script> // Change title document.getElementById("main-title").innerHTML = "New Dynamic Title!"; // Change all paragraph colors const paragraphs = document.getElementsByTagName("p"); for (let i = 0; i < paragraphs.length; i++) { paragraphs[i].style.color = "#34d399"; } </script>

DOM Selectors: Class, querySelector & querySelectorAll

Task: Practice modern DOM selection methods.

  • Create elements with:
    • Class name "highlight" (at least 3 elements)
    • Class name "special" (at least 2 elements)
  • Use JavaScript to:
    • Change the background of ALL elements with class "highlight" using getElementsByClassName
    • Change the text color of the FIRST element with class "special" using querySelector
    • Add a border to ALL elements with class "special" using querySelectorAll
<script> // getElementsByClassName const highlights = document.getElementsByClassName("highlight"); for (let el of highlights) { el.style.background = "#fefcbf"; } // querySelector (first match) const firstSpecial = document.querySelector(".special"); firstSpecial.style.color = "#805ad5"; // querySelectorAll (all matches) const allSpecial = document.querySelectorAll(".special"); allSpecial.forEach(el => { el.style.border = "3px solid #e53e3e"; }); </script>
Submit: Save as task7-query-selectors.html

Interactive DOM Challenge

Task: Build a page with buttons that trigger DOM changes.

  • Create a page with:
    • A <div> with id="content" containing some text
    • An <input> field and a <button>
    • A <ul> with id="item-list" (empty initially)
  • Add JavaScript to:
    • Change the content of #content when a button is clicked
    • Add items to the list when the user types in the input and clicks "Add"
    • Toggle the background color of the page when a "Toggle Theme" button is clicked
<script> // Change content document.getElementById("changeBtn").onclick = function() { document.getElementById("content").innerHTML = "You changed this content!"; }; // Add list item document.getElementById("addBtn").onclick = function() { const input = document.getElementById("itemInput"); const li = document.createElement("li"); li.textContent = input.value; document.getElementById("item-list").appendChild(li); input.value = ""; }; // Toggle theme let dark = true; document.getElementById("themeBtn").onclick = function() { document.body.style.background = dark ? "#1a2338" : "#05070f"; dark = !dark; }; </script>
Submit: Save as task8-interactive.html
