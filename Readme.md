# Class 2: Development Environment Setup - Interactive Slide Deck

An interactive, presentation-style HTML document that teaches students how to set up a professional web development environment using Visual Studio Code, essential extensions, proper folder structures, and developer workflows.

## 🎯 Overview

This is an **interactive slide deck** for Class 2 of Month 1, Week 1 of a web development curriculum. Students learn:

- What a development environment is and why it matters
- Visual Studio Code features and essential shortcuts
- 8 must-have VS Code extensions (Live Server, Prettier, ESLint, etc.)
- Professional project folder structure
- Emmet abbreviations (HTML shortcuts)
- Live Server with hot reload
- Integrated terminal usage
- Multi-cursor editing and other power features

The deck includes **10 interactive Q&A questions** that students can click to reveal answers.

## 📋 Topics Covered

| Section | Description |
|---------|-------------|
| Development Environment | What it is and why professionals invest in it |
| VS Code Features | Command Palette, Multi-cursor, Terminal, Emmet, Git, Snippets |
| VS Code Settings | Auto Save, Format on Save, Tab Size, Theme |
| 8 Essential Extensions | Live Server, Prettier, ESLint, Auto Rename Tag, GitLens, Path Intellisense, Material Icon Theme, Color Highlight |
| Professional Folder Structure | How to organize projects like a pro |
| Emmet Abbreviations | HTML shortcuts that save hours of typing |
| Live Server & Hot Reload | Instant browser preview on save |
| Integrated Terminal | Run commands without leaving VS Code |
| First Project Setup | Step-by-step hands-on tutorial |
| Assignments | Basic tasks + extended challenges |
| Knowledge Check | 10 interactive Q&A questions |

| ESLint | JavaScript error detection |
| Auto Rename Tag | Syncs HTML closing tags |
| GitLens | Git history and blame annotations |
| Path Intellisense | Autocompletes file paths |
| Material Icon Theme | Visual file type icons |
| Color Highlight | Shows color preview squares |

## 📝 Assignments Included

### Basic Tasks
- Install VS Code and all 8 extensions
- Create proper folder structure
- Run Live Server and verify auto-refresh
- Customize theme and settings

### Extended Challenges
- Create a complete portfolio project structure
- Practice all Emmet shortcuts
- Test extension error detection
- Configure Prettier with `.prettierrc`
- Use multi-cursor editing
- **Bonus:** Create custom snippet
