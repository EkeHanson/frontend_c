📋 Your Tasks

Task 1 Style the Main Heading

Add CSS to make the <h1> heading dark blue with a bottom border.

h1 { color: #1e3a5f; border-bottom: 3px solid #2c6b9b; padding-bottom: 0.5rem; }

Task 2 Style Subheadings

Style all <h2> headings with a left border and blue color.

h2 { color: #2c6b9b; border-left: 4px solid #2c6b9b; padding-left: 0.8rem; margin-top: 1.5rem; margin-bottom: 0.5rem; }

Task 3 Style Paragraphs

Make paragraphs larger and easier to read with the right font size and color.

p { font-size: 1.05rem; color: #334155; margin-bottom: 0.8rem; }

Task 4 & 5 Style Info Boxes

Style the blue info box and its icon.

.info-box { background: #eef4fa; border-left: 4px solid #2c6b9b; padding: 1rem; border-radius: 8px; margin: 0.5rem 0; }
.info-box i { color: #2c6b9b; margin-right: 0.5rem; }

Task 6 & 7 Style Tip Boxes

Style the yellow tip box and its icon.

.tip-box { background: #fef9e7; border-left: 4px solid #f59e0b; padding: 1rem; border-radius: 8px; margin: 0.5rem 0; }
.tip-box i { color: #f59e0b; margin-right: 0.5rem; }

Task 8 Style Code Blocks

Make code blocks look like real code with a dark background and monospace font.

.code-block { background: #1e293b; color: #e2e8f0; padding: 1rem; border-radius: 8px; font-family: 'Courier New', monospace; margin: 0.8rem 0; overflow-x: auto; }

Task 9 & 10 Style Task Cards

Style each task card and its heading.

.task-card { background: #f8faff; border: 1px solid #dce3ed; padding: 1rem; border-radius: 8px; margin-bottom: 1rem; box-shadow: 0 2px 8px rgba(0,0,0,0.04); }
.task-card h3 { color: #1e3a5f; margin-bottom: 0.3rem; }

Task 11 Style Badges

Style the task badges to make them stand out.

.badge { background: #2c6b9b; color: white; padding: 0.2rem 0.8rem; border-radius: 20px; font-size: 0.75rem; font-weight: 600; display: inline-block; margin-right: 0.3rem; }

Task 12 Style List Items

Style the list items inside task cards with a custom bullet.

.task-card li { padding: 0.3rem 0; border-bottom: 1px dashed #e2e8f0; list-style-type: none; }
.task-card li:last-child { border-bottom: none; }
.task-card li::before { content: "✓"; color: #10b981; margin-right: 0.5rem; }

Task 13 & 14 Style Submit Button

Style the submit button with hover effect.

.submit-btn { background: #2c6b9b; color: white; border: none; padding: 0.6rem 1.8rem; border-radius: 30px; font-weight: 600; cursor: pointer; transition: 0.2s; }
.submit-btn:hover { background: #1a3f5f; }

Task 15 Style Footer

Style the footer at the bottom of the page.

.footer { border-top: 1px solid #e2e8f0; padding-top: 1rem; text-align: center; color: #64748b; font-size: 0.85rem; margin-top: 1.5rem; }
