HTML Forms: Collecting User Input

An HTML form is used to collect user input. The user input is most often sent to a server for processing.

<form>
<input>
Attributes
Elements

The <form> Element

The HTML <form> element is used to create an HTML form for user input:

<form>
  . form elements .
</form>

The <form> element is a container for different types of input elements, such as: text fields, checkboxes, radio buttons, submit buttons, etc.

All the different form elements are covered in this chapter: HTML Form Elements.

The <input> Element

The HTML <input> element is the most used form element.

An <input> element can be displayed in many ways, depending on the type attribute.

<input type="text"><input type="radio"><input type="checkbox"><input type="submit"><input type="button">
TypeDescription
Single-line text input
Radio button (one of many)
Checkbox (zero or more)
Submit button
Clickable button
All the different input types are covered in the next chapter: HTML Input Types.

The Action Attribute

The action attribute defines where to send form data when submitted.

<form action="/action_page.php">
  <label for="fname">First name:</label>
  <input type="text" id="fname" name="fname">
  <input type="submit" value="Submit">
</form>
Tip: If the action attribute is omitted, the action is set to the current page.

The Target Attribute

The target attribute specifies where to display the response after submitting the form.

ValueDescription
_blank New window or tab _self Current window (default) _parent Parent frame _top Full body of window
<form action="/action_page.php" target="_blank">

The Method Attribute

The method attribute specifies the HTTP method (GET or POST).

<form method="get">
<form method="post">
📌 GET: Appends data to URL (visible, 2048 char limit, bookmarkable)

📌 POST: Sends data in HTTP body (invisible, no size limit, more secure)

The <label> Element

The <label> element defines a label for form elements, improving accessibility and click area.

The <select> Element

The <select> element defines a drop-down list:

<label for="cars">Choose a car:</label>
<select id="cars" name="cars">
  <option value="volvo">Volvo</option>
  <option value="saab" selected>Saab</option>
</select>
• Use selected for pre-selected options
• Use size for number of visible values
• Use multiple for multi-select

The <textarea> Element

The <textarea> defines a multi-line input field:

<textarea name="message" rows="4" cols="30">Text here...</textarea>

The <button> Element

The <button> defines a clickable button:

<button type="button" onclick="alert('Hello!')">Click Me</button>
Important: Always specify the type attribute for buttons.

Grouping & Advanced Elements

<fieldset> groups related data, <legend> provides a caption. <datalist> offers autocomplete options.

<fieldset>
  <legend>Personal Info</legend>
  <input list="browsers">
  <datalist id="browsers">
    <option>Chrome</option>
  </datalist>
</fieldset>
The <output> element represents the result of a calculation.
