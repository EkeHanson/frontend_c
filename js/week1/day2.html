Day 1 · JavaScript Foundations

What is JavaScript? Variables, data types, and your first script

2 hours · theory + lab Beginner browser + DevTools
What is JavaScript?

JavaScript is the programming language of the web. It brings pages to life — handling user interactions, updating content, and communicating with servers.

Key fact: JavaScript is one of the three core technologies of the web, alongside HTML (structure) and CSS (style).

Today we’ll write our first JavaScript, learn about variables, and see how the browser executes code.

Your first script

JavaScript can be written directly inside HTML using the <script> tag. Let’s say "Hello, World!"

<!-- inside your HTML -->
<script>
  console.log("Hello, World!");
</script>
Output in DevTools console: Hello, World!

Pro tip: Open DevTools (F12) → Console tab to see the output.

Variables: storing data

Variables are containers for values. In JavaScript, we use let, const, and var (we focus on let and const).

let (mutable)

let age = 25;
age = 26; // ✅ allowed

const (immutable)

const birthday = "1999-01-01";
// birthday = "2000-01-01"; ❌ error
Data types: number, string, boolean, null, undefined, object, array.
Interactive demo

Click the button — the script reads your name and greets you.

// JavaScript behind the button
const btn = document.getElementById("greetBtn");
btn.addEventListener("click", function() {
  let name = document.getElementById("nameInput").value;
  document.getElementById("greetOutput").innerText = "👋 Hello, " + name;
});
Lab: build a simple counter

Task: create a button that increments a number and displays it.

  • Use let counter = 0;
  • On button click, increase counter and update the display
  • Bonus: add a reset button

Live counter: 0

This is your first interactive JS component!

// counter logic
let count = 0;
const display = document.getElementById("counterDisplay");
document.getElementById("incBtn").addEventListener("click", () => {
  count++; display.innerText = count;
});
document.getElementById("resetBtn").addEventListener("click", () => {
  count = 0; display.innerText = count;
});
Key takeaways

Concepts

  • JavaScript adds interactivity
  • Variables with let and const
  • Data types: string, number, boolean
  • console.log() for debugging

Tools
