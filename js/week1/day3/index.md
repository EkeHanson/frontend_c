## 🔍 What You Learned Applied

| Concept | How It's Used in the Quiz App |
|---------|-------------------------------|
| `let`, `const` | All variables declared with proper scope |
| Strings | Questions, options, messages |
| Numbers | Score, question index, progress |
| Arrays | Questions array, user answers array |
| Objects | Each question with question, options, correct, explanation |
| Arithmetic Operators | `++` for score increment, `%` for modulo (not used but available) |
| Assignment Operators | `+=` for string building, `=` for assignment |
| Comparison Operators | `===` for answer checking, `<`, `>`, `>=`, `<=` for grading |
| Logical Operators | `&&` for state checking, `||` for keyboard events |
| if/else | Correct/wrong feedback, grading, state management |
| Ternary Operator | Icon display, class assignment, message selection |
| for Loop | Displaying options, building results |
| forEach | Iterating over options and results |
| String Methods | `slice()` for preview, `toUpperCase()` for formatting, `split()` (used in options) |
| Functions | `startQuiz()`, `loadQuestion()`, `selectOption()`, `goToNext()`, `showResults()`, `restartQuiz()` |
| Events | `addEventListener` for click and keydown |
| DOM | `getElementById`, `querySelector`, `innerHTML`, `textContent`, `classList` |
| Template Literals | HTML building with backticks |
| Booleans | `isAnswered`, `isCorrect`, state tracking |

This Quiz App is a complete, polished project that demonstrates everything from Day 1 and Day 2. Students can extend it by adding more questions, a timer, difficulty levels, or saving high scores to localStorage!
