Introduction to Operators

Operators are used for mathematical and logical computations.

Basic Operators:
  • = The Assignment Operator assigns values
  • + The Addition Operator adds values
  • * The Multiplication Operator multiplies values
  • > The Comparison Operator compares values
// Assignment Operator (=)
let x = 10; // Assigns 10 to x
let y = 5; // Assigns 5 to y
let z = x + y; // Assigns 15 to z

Addition

let x = 5;
let y = 2;
let z = x + y; // z = 7

Multiplication

let x = 5;
let y = 2;
let z = x * y; // z = 10

String Addition

The + operator can also be used to concatenate (join) strings.

let text1 = "John";
let text2 = "Doe";
let text3 = text1 + " " + text2; // "John Doe"
// The += operator can also concatenate strings
let text1 = "What a very ";
text1 += "nice day"; // "What a very nice day"
Adding Numbers and Strings:
  • 5 + 5 10 (number)
  • "5" + 5 "55" (string)
  • "Hello" + 5 "Hello5" (string)

If you add a number and a string, the result will be a string!

Truthy & Falsy Values

In JavaScript, values are either truthy or falsy when used in a boolean context.

Falsy Values

false 0 -0 0n "" (empty string) null undefined NaN

Truthy Values

"0" "false" [] (empty array) {} (empty object) 42 "Hello" true function() {}
Common Mistake: "0" and "false" are truthy because they are non-empty strings!
// Everything with a "value" is true
Boolean(100); // true
Boolean("Hello"); // true
Boolean([]); // true

// Everything without a "value" is false
Boolean(0); // false
Boolean(""); // false
Boolean(null); // false

Ternary Operator

The ternary (conditional) operator is a shorthand for if...else.

Syntax:
(condition) ? expression1 : expression2
  • If condition is true, returns expression1
  • If condition is false, returns expression2
let age = 20;
let status = (age >= 18) ? "Adult" : "Minor";
// status = "Adult"

Using Ternary

let isMember = true;
let discount = isMember ? 0.2 : 0;

Same as if/else

if (isMember) {
  discount = 0.2;
} else {
  discount = 0;
}
Tip: Use the ternary operator for simple conditionals to make your code more concise.
JavaScript Booleans

A Boolean can only have one of two values: true or false.

Key Characteristics:
  • true and false are boolean data types
  • They are the only possible boolean values
  • Must be written in lowercase
  • Must be written without quotes
// Comparisons return booleans
let x = 5;
(x == 8); // false
(x != 8); // true
(x > 8); // false
(x < 8); // true
Warning: Do not create Boolean objects with new Boolean(). They produce unexpected results.
let x = false; // boolean primitive
let y = new Boolean(false); // boolean object
(x == y); // true
(x === y); // false

For Loop

The for loop executes a block of code a number of times.

Syntax:
for (exp1; exp2; exp3) {
  // code block to be executed
}
  • exp1: Executed once before the loop starts (initialize)
  • exp2: Defines the condition for the loop to run
  • exp3: Executed after each iteration (increment)
for (let i = 0; i < 5; i++) {
  text += "The number is " + i + "
";
}
Looping through arrays:
const cars = ["BMW", "Volvo", "Saab"];
for (let i = 0; i < cars.length; i++) {
  text += cars[i];
}

While & Do-While Loops

While Loop

Executes code as long as the condition is true.

while (i < 10) {
  text += "The number is " + i;
  i++;
}

Don't forget to increment!

Do-While Loop

Executes code once before checking the condition.

do {
  text += "The number is " + i;
  i++;
} while (i < 10);

Always runs at least once.

For vs While: A while loop is similar to a for loop with exp1 and exp3 omitted.
// For loop
for (let i = 0; i < cars.length; i++) { ... }

// Same as while
let i = 0;
while (i < cars.length) {
  ...
  i++;
}
Break & Continue

break

Exits the loop immediately.

for (let i = 0; i < 10; i++) {
  if (i === 3) { break; }
  text += i;
}
// Output: 0 1 2

continue

Skips the current iteration and continues.

for (let i = 0; i < 5; i++) {
  if (i === 3) { continue; }
  text += i;
}
// Output: 0 1 2 4
Labeled Break: You can break out of nested loops with labels.
loop1: for (let j = 1; j < 5; j++) {
  loop2: for (let i = 1; i < 5; i++) {
    if (i === 3) { break loop1; }
  }
}
String Methods Overview

Javascript strings are primitive and immutable — all string methods produce a new string without altering the original.

Extract

  • slice(start, end)
  • substring(start, end)
  • substr(start, length) deprecated

Trim & Pad

  • trim()
  • trimStart()
  • trimEnd()
  • padStart()
  • padEnd()

Replace & Split

  • replace()
  • replaceAll()
  • split()
  • repeat()
let text = "Apple, Banana, Kiwi";
text.slice(7, 13); // "Banana"
text.toUpperCase(); // "APPLE, BANANA, KIWI"
text.split(","); // ["Apple", " Banana", " Kiwi"]
Remember: Strings are immutable. Methods return new strings — they don't change the original!
