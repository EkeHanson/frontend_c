JavaScript Output Methods

Live demo for students — click buttons to see each method in action. Compare innerHTML vs innerText, try document.write(), alert, and console.log.
innerHTML
Changes HTML content of an element — parses and renders HTML tags.
element.innerHTML = "Hello <b>World</b>";
Live preview
Hello World
innerText
Changes only plain text — shows HTML tags as literal text.
element.innerText = "Hello <b>World</b>";
Live preview
Hello <b>World</b>
document.write()
Writes directly to the HTML document. After page load it overwrites everything!
document.write("Hello from write()");
Try with caution
Clicking the button will replace the entire page content (then you'll need to refresh).

window.alert()
Shows a pop-up alert box — blocks the page until dismissed.
window.alert("Hello from JavaScript!");
Alert preview

console.log()
Outputs to browser console — great for debugging. Open DevTools (F12) to see.
console.log("Hello from console!");
