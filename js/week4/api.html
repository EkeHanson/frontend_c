API Integration · Before & After

What is an API? API stands for Application Programming Interface. It's like a waiter at a restaurant — your app (the customer) asks the API (the waiter) for data, and the API brings it from the server (the kitchen).
Why use APIs? APIs let you use data from other services (like weather, news, user data) without building everything from scratch. They make your app more powerful and dynamic.

How API Integration Works

1. Request

Your app asks the API for data using a URL (endpoint).

fetch('https://api.example.com/users')

2. Response

The API sends back data (usually in JSON format).

[ { "name": "John", "email": "john@email.com" }, { "name": "Jane", "email": "jane@email.com" } ]

3. Display

Your app renders the data into HTML elements.

users.forEach(user => { const card = createUserCard(user); container.appendChild(card); });

4. Update

Data stays dynamic — refresh the page to get the latest data.

No hardcoding needed!
